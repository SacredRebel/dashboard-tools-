# .ux-profile.md

Place this at the project root (as `.ux-profile.md`). The VectorLab UX skills read it before making layout, color, motion or copy decisions. Agents without those skills should treat it as project rules too.

## Aesthetic reference
<e.g. "Notion/Things restraint with a warm, editorial feel. Motion: Stripe-like 150–200ms.">

## Theme
data-theme="<name>" · tokens in styles/tokens.css

## Accessibility target
WCAG 2.2 AA · hit targets 44×44px · reduced-motion respected

## Voice & microcopy
- Tone: warm, brief, confident. Second person ("your clients").
- Vocabulary: <client's words: "clients" not "leads", "Discovery call", …>
- Buttons: verb + object. Never "Submit", "OK".

## Icon library
Lucide, 1.5px stroke, 16px inline / 20px nav.

## Banned (in addition to docs/design/05-anti-patterns.md)
- <e.g. no emoji in UI>
- <e.g. no blue — client dislikes it>

## Density
Comfortable (row height 48px) / Compact (40px)
