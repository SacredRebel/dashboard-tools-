# motion@12.23.12 (vendored)

- **Source:** https://motion.dev · npm package `motion`
- **Version:** 12.23.12
- **License:** MIT (see LICENSE.md)
- **What for:** Vanilla `animate`, `scroll`, `inView`, spring helpers for gallery dashboards (count-ups, staggered entrances, chart draw-ins). Prefer CSS tokens in `design-system/tokens.css` for simple hovers.
- **How to load (relative, no CDN):**
  ```html
  <script src="../_vendor/motion@12.23.12/motion.js"></script>
  ```
- **Do not** use the React builds in the static gallery. React apps should `npm install motion` instead.
- Docs: `docs/design/09-motion-system.md`
